# BarberFlow Frontend

Angular web application for BarberFlow. It contains the public product pages, owner authentication, and the private barbershop dashboard.

From this directory:

```bash
pnpm install
pnpm start
```

The development server is available at <http://localhost:4200> and proxies API requests to <http://localhost:8080>.

```bash
pnpm test --watch=false
pnpm build
```

See the repository-level [`README.md`](../README.md) and [`ARCHITECTURE.md`](../ARCHITECTURE.md) for full setup and architecture details.
